# Royal Guardian Product Spec

Royal Guardian is a universal AI agent platform for individuals and organizations. Customers should be able to register, subscribe, configure agents, connect tools and data sources, delegate approved work, review actions, and deploy Royal Guardian IT to Windows devices.

The first flagship template is **Royal Guardian IT**, an AI Tier-1 technician that follows: understand → observe → diagnose → plan → approve → act → verify → document → escalate.

The platform must remain vendor-portable. AI providers, billing providers, OAuth providers, telephony providers, queues, storage and hosting are integration boundaries rather than inseparable application logic.
