# Implementation Plan

## Phase 1 — Core platform foundation
Implemented in this pass: repository audit, architecture docs, relational schema, auth, tenancy/RBAC, web shell, agents foundation, tests.

## Phase 2 — Agent runtime
Implement provider interfaces, structured tool calls, run records, generic approvals and cost accounting. Requires at least one AI provider key for end-to-end verification.

## Phase 3 — Integrations
Implement reusable OAuth state/PKCE/token encryption; then Google and Microsoft first. Requires external developer app registrations.

## Phase 4 — Knowledge and memory
Document ingestion, secure object storage, chunking/embedding, citation-aware retrieval, memory policies and deletion.

## Phase 5 — Workflows
Persistent worker/queue, scheduled runs, triggers, workflow definitions and execution traces.

## Phase 6 — Royal Guardian IT hardening
Merge legacy Windows modules into endpoint diagnostics, add Windows service, DPAPI credential storage, incident model, verification steps and action policy engine.

## Phase 7 — Commercialization
Stripe subscriptions/entitlements, download center, installer/MSI, signed updates, code-signing pipeline and production cloud deployment.

## Phase 8 — Channels/marketplace
Voice/telephony, email channel, templates, `.guardian` packaging and marketplace foundations.
